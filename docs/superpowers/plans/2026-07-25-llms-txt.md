# llms.txt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a repo-root `llms.txt` file following the llmstxt.org convention, giving an AI agent a curated entry point into Kanbrain's docs.

**Architecture:** Single static markdown file at the repository root. No build step, no generation script, no other files touched.

**Tech Stack:** Plain markdown, following the llmstxt.org format (H1 title, blockquote summary, context paragraph, `## Docs` link list).

## Global Constraints

- File location: repo root, exact filename `llms.txt` (not `.md`).
- Links must point to raw GitHub content (`https://raw.githubusercontent.com/codekillerss/kanbrain/main/<path>`), not `github.com/.../blob/...` HTML pages.
- Only `README.md` and `CHANGELOG.md` are linked. Do not link `docs/superpowers/specs` or `docs/superpowers/plans` — spec decision, they're session-generated planning notes, not curated docs.
- No `llms-full.txt` and no automation/build step — spec decision, hand-maintained is sufficient for two linked files.
- Content must match the spec's approved draft in `docs/superpowers/specs/2026-07-25-llms-txt-design.md` verbatim (title, summary, context paragraph, link descriptions).

- [ ] **Step 1: Create the file with the approved content**

Create `llms.txt` at the repository root with exactly this content:

```
# Kanbrain

> VS Code extension that shows the active Azure DevOps work item and its children in a side panel, with per-status "skill" buttons that hand context to a coding agent.

Kanbrain connects a VS Code side panel to Azure DevOps boards. It surfaces the active work item (and its children), and lets each board status trigger a "skill" — a markdown file with placeholders resolved from the real work item's data, sent to an AI coding agent running in an integrated terminal. Skills can also be global (not tied to a status), for actions like explaining a card on demand.

## Docs

- [README](https://raw.githubusercontent.com/codekillerss/kanbrain/main/README.md): Installation and setup walkthrough, skill/global skill configuration, skill placeholders, development commands, and the manual verification checklist.
- [CHANGELOG](https://raw.githubusercontent.com/codekillerss/kanbrain/main/CHANGELOG.md): Version history and notable changes.
```
